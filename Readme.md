# Cyber Claws 🐾

 ES un proyecto web de para las materias de Diseño de software y programacion que es  interactivo con una estética cyberpunk, desarrollado como una historia que tiene  5 secciones principales, un glosario de personajes interactivo y una navegación fluida.

##  Características del Proyecto
- **Aesthetic Cyberpunk:** Diseño oscuro (`#0b0f19`) combinado con acentos de neón vibrantes (cian, rojo, oro y púrpura).
- **Estructura Modular:** 5 capítulos secuenciales con un diseño alternado de tarjetas, encabezados fijos y pie de página profesional.
- **Interactividad (JS):** Glosario de personajes equipado con un sistema de acordeón dinámico.
- **Control de Versiones:** Integración con Git y GitHub mediante el uso de ramas y resolución de conflictos.

##  Estructura del Repositorio
- `seccion 1.html` a `seccion 5 .html`: Capítulos de la historia principal.
- `GLosario de personajes.html`: Directorio interactivo de personajes.
- `CSS/`: Estilos personalizados para cada sección.
- `IMG/`: Recursos gráficos y arte conceptual del universo cyberpunk.
- `script.js`: Lógica interactiva del acordeón.

##  Tecnologías Utilizadas
- **HTML5** para la estructura semántica.
- **CSS3** (Flexbox, Grid, Variables y animaciones personalizadas).
- **JavaScript (ES6+)** para la interactividad de la interfaz.
- **Git & GitHub** para el control de versiones y trabajo en equipo.
